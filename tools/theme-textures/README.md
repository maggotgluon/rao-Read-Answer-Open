# Theme textures / ตัวสร้างพื้นผิว

`generate.html` draws the dusk theme's textures with seeded noise (same output every run):
desk.png, paper-grain.png, grunge.png, ink_.png (alternative ink sprite), buttons/primary.png, buttons/seal.png.
Open it in Chrome to preview; the page exposes `window.RAO_TEXTURES` (data URLs keyed by path) for saving.
The active ink sprite `textures/ink.png` is not written by this tool.

เปิดใน Chrome เพื่อดูตัวอย่าง ทุกภาพสุ่มแบบมี seed · ไฟล์ ink.png ที่ใช้จริงไม่ถูกเขียนทับ
